# On a text console

A **text console** is the black, full-screen login you get with **Ctrl+Alt+F3** (or when the desktop won't start). It has only 16 colours and a small font, with no emoji.

alacrittyForge notices it's on a console and switches by itself to colours and characters the console can show: straight frame corners, **+** instead of a tick, **!** instead of a warning sign. Everything works the same way.

- Help is on **F1** there; the console can't send **Ctrl+H**.
- If a terminal window looks wrong, start alacrittyForge with `FORGE_ASCII=1 alacrittyforge` to use console mode anyway.
