# Advanced settings

Less common settings. In **Settings ▸ Advanced**. Most people never need these.

## The settings

- **Window name for the desktop** and **Window instance name**: the names your desktop's window rules see (on Wayland, the app id). New windows only.
- **Title bar style**: ask for a **Dark** or **Light** title bar instead of following the desktop.
- **Keep on top**: keep Alacritty's windows above all others.
- **Resize in whole characters**: grow and shrink the window one character at a time.
- **See-through coloured backgrounds**: make every coloured background see-through with the window, not only the main one.
- **Move letters right** and **Move letters up**: nudge every letter inside its space, in pixels.
- **Word separators**: the characters that end a word when you double-click to select it.
- **Allow alacritty msg**: let the `alacritty msg` command control open windows.
- **Log detail**, **Keep the log**, **Log every event**: what Alacritty writes to its log, for reporting a problem.
- **Drawing method** and **Prefer EGL**: change only to work around a drawing problem; the best is picked by itself.
- **Show drawing time** and **Highlight redrawn areas**: tools for measuring Alacritty's speed.

Settings only Macs use aren't shown.

Alacritty names on this page: `window.class`, `window.decorations_theme_variant`, `window.level`, `window.resize_increments`, `colors.transparent_background_colors`, `font.glyph_offset`, `selection.semantic_escape_chars`, `general.ipc_socket`, `debug.*`.
