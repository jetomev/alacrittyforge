# All keys

## Everywhere

- **Tab** / **Shift+Tab**: next / previous field or button
- **Enter**: open a list, press a button, confirm
- **Space**: flip a switch
- **↑ ↓** in a number: step through its presets
- **Esc**: close a window, or leave a Help page (this manual, Keys, About, License) for the page you were on
- **1 – 6**: the menu, in order: Overview, Settings, Themes, Shortcuts, Backups, then **Help** (6). Pressing **6** again closes Help.
- **Ctrl** + the underlined letter: the same (**Ctrl+O** Overview, **Ctrl+S** Settings, **Ctrl+T** Themes, **Ctrl+R** Shortcuts, **Ctrl+B** Backups, **Ctrl+H** Help). These work even while you type in a field; numbers don't, so a field keeps its digits.
- How the letters are picked, the same in every Forge app: the first letter of the name, unless another entry already has it; then the next letter of the name. Settings has S, so Shortcuts gets R. Help is always H, Quit always Q.
- **Help** stays lit while its menu is open. Its pages, **Manual**, **Keys**, **About** and **License**, open inside the app with Help lit; **Esc** goes back to the page you came from.
- **F10** or **S**: save, with a review first
- **R**: read the file again (your unsaved changes stay)
- **F1**: help on what is selected
- **M**: this manual, as a page of the app; **Backspace** goes to the manual page you read before
- **?**: the list of keys, as a page of the app
- **Q** or **Ctrl+Q**: quit (asks first if something isn't saved)

Every button shows its key in brackets after its name, like **Back Up Now (n)** or **Change (F2)**.

## Inside hypeForge Settings

When alacrittyForge is open as a page of **hypeForge Settings**, there is no **Quit**: not in the menu bar, and **Q** and **Ctrl+Q** do nothing. You close it from Settings, which asks alacrittyForge first, so unsaved changes still get the **Before you go** window.

## Themes

- **Enter**: use the theme you picked
- **A**: adjust colours (makes your own copy)
- **I**: install a theme file

## Shortcuts

- **+**: add a shortcut (then press its keys to record them)
- **F2** or **Enter**: change one of yours
- **Delete**: remove one of yours

## Backups

- **R**: restore the backup you picked (asks first)
- **N**: back up now
- **D**: delete the backup you picked (asks first)

Letter keys never act while you're typing in a field.

## From the terminal

- `alacrittyforge`: open it
- `alacrittyforge --version`: print the version
- `alacrittyforge --help`: print the usage
