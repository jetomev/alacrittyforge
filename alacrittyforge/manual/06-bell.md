# Bell

What happens when a program rings the bell (for example, when you press Backspace on an empty line). In **Settings ▸ Bell**.

## The settings

- **Flash the screen**: how long the screen flashes, in milliseconds. **0** means no flash, which is what Alacritty does unless you set it.
- **Flash colour**: the colour of the flash, as a code like **#ffffff** (white).
- **How it fades**: how the flash fades out. **Evenly** is Alacritty's own; the others start fast and slow down.

Alacritty names on this page: `bell.duration`, `bell.color`, `bell.animation`.
